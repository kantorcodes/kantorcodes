# Michael Kantor

President of [Hashgraph Online](https://github.com/hashgraph-online) and Co-Creator of Hashinals.  
I build HOL Guard, Hiero standards, and open-source tooling for AI agents.

## Core focus

- HOL Guard: runtime antivirus and firewall for AI agents
- Hiero standards and protocol specifications
- Curated awesome lists for AI plugins and skills
- Registry infrastructure and developer tooling

## Key work at Hashgraph Online

### 1) HOL Guard
[`hol-guard`](https://github.com/hashgraph-online/hol-guard)  
Open-source antivirus and firewall for AI agents. Blocks risky tools, secret access, prompt injection, malicious packages, MCP servers, plugins, and skills at runtime.

[`hol-guard-plugin`](https://github.com/hashgraph-online/hol-guard-plugin)  
Security integrations for AI harnesses, skills, MCP servers, agent frameworks, and plugin marketplaces.

### 2) Hiero Consensus Specifications
[`hiero-consensus-specifications`](https://github.com/hiero-ledger/hiero-consensus-specifications)  
Canonical Hiero Consensus Specifications, originally written and maintained by Hashgraph Online.

### 3) Awesome lists
[`awesome-ai-plugins`](https://github.com/hashgraph-online/awesome-ai-plugins)  
Curated plugins and skills for Claude Code, Codex, ChatGPT, Gemini, Pi, Grok, and more. Live at [hol.org/plugins](https://hol.org/plugins).

[`awesome-codex-plugins`](https://github.com/hashgraph-online/awesome-codex-plugins)  
OpenAI Codex and ChatGPT plugins, skills, and resources.

[`awesome-grok-plugins`](https://github.com/hashgraph-online/awesome-grok-plugins)  
xAI Grok plugins, skills, and resources.

### 4) Standards and implementation tooling
[`standards-sdk`](https://github.com/hashgraph-online/standards-sdk)  
Official Hashgraph Online Standards SDK for production integrations.

### 5) Agent and registry infrastructure
[`hashnet-mcp-js`](https://github.com/hashgraph-online/hashnet-mcp-js)  
Universal MCP server for discovering and connecting agents across ecosystems.

[`registry-broker-skills`](https://github.com/hashgraph-online/registry-broker-skills)  
Skills for searching, chatting with, and registering agents across protocols.

### 6) Additional ecosystem tooling
